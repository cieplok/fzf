## Goal

Let `--bind shift-space:<action>` work for users on terminals that force-enable the Kitty keyboard protocol (which send Shift+Space as CSI `32;2u`). Today fzf rejects `shift-space` as an unsupported key name, and the `\e[32;2u` sequence is dropped as an unimplemented CSI-u key.

## Scope

Input key parsing and the default (Light/CSI) renderer:

- `src/tui/tui.go` — new `ShiftSpace` event in the `EventType` enum.
- `src/tui/eventtype_string.go` — regenerated by `stringer`.
- `src/options.go` — `shift-space` case in `parseKeyChords`.
- `src/tui/light.go` — accept the `\e[32;2u` sequence.
- `man/man1/fzf.1` — document the key name.
- Tests: `src/options_test.go`, `src/tui/light_test.go`, `src/tui/light_csi_test.go`.

## Implementation Plan

### Phase 1 — Key name and event

- Step 1.1: Add `ShiftSpace` to the `EventType` enum in `src/tui/tui.go`, grouped with `CtrlSpace`.
- Step 1.2: Regenerate `src/tui/eventtype_string.go` with `stringer` (never hand-edit).
- Step 1.3: Add `case "shift-space": add(tui.ShiftSpace)` to `parseKeyChords` in `src/options.go`, and cover the name (and its `KeyName()` round-trip) in `src/options_test.go`.

### Phase 2 — CSI-u parsing

- Step 2.1: In `src/tui/light.go`, accept exactly `\e[32;2u` as `ShiftSpace`, leaving every other CSI-u key `Invalid` (narrow special-case per the brief).
- Step 2.2: Add unit tests in `src/tui/light_test.go` / `src/tui/light_csi_test.go`: the sequence maps to `ShiftSpace` and is consumed whole; other CSI-u keys stay `Invalid`.

### Phase 3 — Documentation

- Step 3.1: Add `shift-space` to the key list in `man/man1/fzf.1`.

## Risks

- The change carves a single exception into a CSI-u parser that deliberately rejects CSI-u keys (see the "Key encodings fzf does not implement" cases in `src/tui/light_csi_test.go`). Scope is deliberately narrow; general CSI-u support is an explicit non-goal.
- `stringer` is not installed locally; Step 1.2 installs it (`go install golang.org/x/tools/cmd/stringer@latest`). The regenerated file is committed, never hand-edited.
- The tcell backend is a non-goal: it does not surface the Shift modifier on the space rune, so a mapping there would be unreachable.
- QA is `skip-qa`: a CSI-u keystroke is not reachable by the browser provider.
